# 📅 Schema Vecka 18: Next.js Individuellt Projekt

## Mini-portfolio i Next.js. 

Ska planeras, godkännas och visa upp kursens kunskaper.

Grundkrav: Next.js, planering innan start, GitHub Projects, strukturerat arbete med tydliga commits, feature branches, PRs, merge osv

Valbart: API/databas, bibliotek (Tailwind, Prisma, supabase ...), deployment (Vercel eller liknande). 

Planering ska innehålla wireframe, val av data/API och backlog.

Ni arbetar enskilt i projektet men kommer tillhöra en grupp där ni kan bolla tankar och stötta varandra.
